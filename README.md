# 📖 Blogging application

## This project demonstrates the power of modern web development by combining React + Redux on the frontend with Express.js + MongoDB on the backend.

### ✨ Features

### 👤 For Users
📚 Read Articles – Browse all published posts.
🔑 Authentication – Secure sign-up, login, and logout.
💬 Commenting – Add, edit, and delete your own comments.

### 🛡 For Moderators
📝 Publish & Edit Posts – Create and update articles.
✏️ Manage Comments – Edit or delete comments from other users.

### 👑 For Administrators
⚙️ User Management – Assign roles (e.g., make moderators), delete accounts.
🔥 Full Control – Edit or delete any article or comment.

### 🛠 Tech Stack
### Frontend
⚛️ React
– Building UI components.
📦 Redux
– State management (users, posts, comments).
⚡ Vite
– Fast development environment.

### Backend
🚀 Express.js
– Handles API requests & business logic.
🍃 MongoDB
– Database for users, posts, comments.
🔒 JWT + bcrypt
– Authentication & password hashing.
